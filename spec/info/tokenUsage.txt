Token Usage {

Only used inside strings: # ` \ $

P - prefix
S - suffix

` ` -> unused.
`X` -> used.
`-` -> cant ever be used.
`~` -> likely bad idea to use, as it conflicts sometimes.
`/` -> too wierd to use.
`^` -> already used by another token.
